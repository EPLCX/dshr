# DSHR Desktop 使用指南

这篇按界面区域介绍桌面版的全部功能。快捷键按 Windows 写，macOS 上把 `Ctrl` 换成 `Cmd`。

## 窗口布局

```text
┌──────────────┬──────────────────────────────────────────────┐
│ DSHR Desktop │ 工作区 › 会话标题                     ─ □ ✕ │  ← 标题栏
│ + 新会话     ├──────────────────────────────────────────────┤
│              │                                              │
│ 工作区     + │            对话区（消息、工具卡片）          │
│  ▸ my-app    │                                              │
│    · 会话 A  │                                              │
│    · 会话 B  │   ┌──────────────────────────────────────┐   │
│  ▸ docs      │   │ 📁 my-app ▾                          │   │
│ 其他会话     │   │ 描述你想要构建的内容                 │   │  ← 输入卡片
│              │   │ +  标准模式▾  工作区内修改▾  模型▾ ↑ │   │
│ 设置         │   └──────────────────────────────────────┘   │
│ ● 账号状态   │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

- **侧边栏**：新建会话、搜索对话、按工作区分组的会话列表、插件加的入口、设置，以及底部的状态行（还没配置提供商、演示模式时的提醒等；一切正常时不显示）。可以收起成一列图标按钮（见下文）。
- **标题栏**：当前的工作区和会话标题；会话运行中带加载圈，等待审批时带提醒图标。系统的窗口标题同步为“会话标题 - dshr”。
- **对话区**：消息、思考过程、工具卡片和提示。新会话显示首页（标语、“预览版”徽标和输入卡片）。
- **输入卡片**：写消息的地方，也是选工作区、预设、权限和模型的地方。

## 工作区与会话

**工作区**就是 agent 干活的目录：它在这里读写文件、运行命令，项目的 `AGENTS.md` 和 Skills 也从这里读。

- 在首页或输入卡片顶部的工作区标签（文件夹图标 + 名字）里选择目录；运行中不能切换。
- 侧边栏“工作区”标题右边的 `+` 添加工作区；最近用过的工作区排在前面，最多记住 20 个。
- 会话按它所在的工作目录分组，分组可以折叠；分组标题上的 `+` 在这个工作区里新建会话。还没有会话的工作区可以“从列表移除”
  （只是不再显示，不删除任何文件）。
- 没有记录工作区的会话（较早版本创建的）归在“其他会话”下。会话多时点“显示更多”。
- 启动时带一个目录参数（`dshr-desktop <目录>`）会直接以它为工作区打开。

**会话**是一段连续的对话，完整记录在 `~/.dshr/sessions/<会话 id>/` 的日志里（见 [会话与日志格式](sessions.md)）。

- 点“新会话”（`Ctrl+N`）开始一段新对话。
- 点“搜索对话”（`Ctrl+K`）按标题找会话：输入的每个词都要出现在标题里，不分大小写，命中的文字高亮；没输入时列出最近的
  20 个会话。每一项下面是所在工作区和最后修改时间。`↑` `↓` 选择，`Enter` 打开，`Esc` 或点弹窗外面关闭。
- 点侧边栏品牌行右边的收起按钮（`Ctrl+B`）把侧边栏收成一列图标：展开、新会话、添加工作区、搜索，底部是插件入口和设置；
  每个图标悬停时显示名字。收起状态记在配置里（`ui.sidebar_collapsed`），下次打开保持不变。
- 会话的“…”菜单（悬停或选中时出现，也可以右键 / 长按）：**重命名**；**删除**——再点一次确认，会话被移到
  `sessions/.trash/`，需要时可以手动找回。运行中的会话要先停止才能删除。
- 侧边栏里运行中的会话带加载圈，等待你审批的带提醒图标；切到别的会话时，后台的会话照常运行。
- 重新打开一个会话时，它上次用的预设、权限模式和模型会一起恢复。
- 输入框里没发出去的字在切换会话时会保留，切回来时放回；新会话的预设、权限模式、模型（含思考等级）沿用这次运行里
  上一个新会话选的。这些只记在内存里，关掉程序再打开就回到配置里的默认值。
- 同一时间只运行一个 dshr 桌面版实例：再次启动时，已经打开的窗口会被调到前台。

## 输入卡片

| 位置 | 控件 | 作用 |
|---|---|---|
| 顶部 | 工作区标签 | 选择这个会话的工作区 |
| 中间 | 输入框 | `Enter` 发送，`Shift+Enter` 换行 |
| 左下 | `+` | 添加附件 |
| 左下 | 预设菜单 | 标准模式、规划模式、审查模式、创造模式，以及插件提供的预设 |
| 左下 | 权限菜单 | 手动模式、工作区内修改、自动审查、完全访问 |
| 右下 | 模型菜单 | 按提供商分组的模型；二级菜单里选思考等级 |
| 右下 | 发送 / 停止 | 运行中且输入框为空时变成停止按钮 |

插件可以在输入卡片上方加面板（例如内置的计划面板），也可以把预设菜单、权限菜单藏起来。

### 附件

点 `+` 选择文件，或者直接 `Ctrl+V` 粘贴剪贴板里的图片、从文件管理器复制的文件。附件随这条消息一起发出：

- **文本文件**：内容在发送时读入并写进会话日志，之后文件再变也不影响这段对话。单个不超过 256 KB；更大的文件请让
  agent 自己用工具去读。
- **图片**：PNG、JPEG、GIF、WebP，单个不超过 5 MB。能看图的模型直接看到图片；不能看图的模型会收到一句说明。

只发附件、不写文字也可以。

### `@` 提及

在输入框里打 `@` 会弹出候选，选中后把内容附到消息里：

- **文件**：在工作区里按名字搜索（遵守 `.gitignore`），单个文件不超过 256 KB。
- **MCP 资源**：已连接的 MCP 服务器提供的资源。
- **插件提供的来源**：插件可以加自己的提及来源（如 issue、文档）。

### `/` 命令

在输入框开头打 `/` 会弹出命令菜单。命令不发给模型，而是由插件或服务器处理：

- 插件导出的斜杠命令：`/<名字>`；
- 插件包里的提示词命令：`/<插件>:<名字>`，把模板里的 `$ARGUMENTS` 换成你在命令后面写的文字，放进输入框或直接发送；
- MCP 服务器的 prompts：`/mcp:<服务器>:<prompt> 参数=值 …`，取到 prompt 的文字后放进输入框，让你先看一眼再发。

### 预设

预设决定这一轮 agent 用什么方式工作，随时可以切换（只影响之后的请求）：

| 预设 | 做什么 |
|---|---|
| 标准模式 | 直接执行任务：调查、修改、验证、汇报 |
| 规划模式 | 只读调查，给出分步方案，不改文件、不运行命令 |
| 审查模式 | 审查当前改动（或你指定的范围），按严重程度列出问题，不主动修改 |
| 创造模式 | 你描述需要的功能，agent 把它写成插件、加载并试用；插件申请的权限经你允许后生效 |

插件可以提供更多预设，出现在内置四项后面。详见 [Agent 的工作方式](agent.md#预设)。

### 权限模式

| 模式 | 读取 | 工作区内修改 | 工作区外修改 | 运行命令、调用外部服务 |
|---|---|---|---|---|
| 手动模式 | 直接执行 | 询问 | 询问 | 询问 |
| 工作区内修改（默认） | 直接执行 | 直接执行 | 询问 | 询问（macOS 沙箱里的命令直接执行） |
| 自动审查 | 直接执行 | 直接执行 | 模型判断风险 | 模型判断风险 |
| 完全访问 | 直接执行 | 直接执行 | 直接执行 | 直接执行 |

“自动审查”会先让当前模型判断这一步的风险：低风险直接执行，有风险时再问你，并在审批处写出理由。
完整规则见 [权限与安全](permissions.md)。

### 模型与思考等级

模型菜单按提供商分组列出“设置 → 模型”里配置的模型。选中一个模型后，二级菜单里可以选思考等级：

| 选项 | 含义 |
|---|---|
| 默认 | 不发送这个参数，由模型自己决定 |
| 关闭 / 低 / 高 / 最高 | 分别对应 `off` / `low` / `high` / `max` |

部分模型不支持关闭思考。新会话的默认模型、思考等级、权限模式和模式在“设置 → 模型 → 新会话默认设置”里改。

## 对话区

### 消息与工具卡片

- 你的消息在右侧的气泡里；模型的回复按 Markdown 显示，思考过程以次要色显示在回复前面。
- 每次工具调用是一张卡片，头部写着工具、参数和状态：**等待批准**、**运行中**、**完成**、**失败**、**已取消**。
  - `edit_file`、`write_file` 的卡片显示改动的行数和 diff；
  - `run_shell` 的卡片在运行时实时显示输出；
  - `delegate`（子代理）的卡片显示子代理每一步在做什么，子代理的审批也挂在这张卡片上；
  - 插件可以给自己的工具画专门的卡片。
- `update_plan` 不显示成卡片：计划显示在输入卡片上方的“计划”面板里，带“已完成 x/y”的进度。
- 消息可以用键盘走：`↑` / `↓` 在消息之间移动，`Ctrl+C` 复制（选了文字时只复制选中的部分），`Esc` 回到输入框。
- 往上翻看历史时，右下角会出现“跳到最新消息”。

### 审批

需要确认的操作，审批框出现在输入框的位置（工具卡片上显示“等待批准”，并提示“请在输入框位置确认”），焦点自动移到第一个选项：

| 选项 | 效果 |
|---|---|
| 允许 | 只放行这一次 |
| 允许，本会话内不再询问此工具 | 这个会话里同一个工具之后都直接放行 |
| 拒绝 | 不执行；模型会收到“用户拒绝了这次调用”，自己调整做法 |

键盘：`↑` `↓` 选择、`Enter` 确认、`1`–`3` 快速选择、`Esc` 拒绝。等审批时点停止，会话立即中断。

有些操作**必须由你亲自确认**（例如给插件授予能力、修改已经授权过的插件）：它们不受权限模式影响（完全访问也会问），
不交给自动审查，也不能设为“本会话不再询问”。

### 提示行

对话里会出现一些灰色提示，说明发生了什么：

- “对话较长，较早的内容已压缩为摘要”——上下文快满时的自动压缩（见 [Agent 的工作方式](agent.md#上下文压缩)）；
- “第 N 次请求失败，正在重试”——网络错误或限流后的自动重试；
- “回复达到单次输出上限，已自动继续”——回复被截断后的自动续写；
- “已中断”“错误：……”——这一轮被停止或出错；
- “此会话分叉自原会话第 N 轮之后”——分叉出来的会话开头。

### 每一轮的结尾

每一轮结束处有一行操作和信息：

- **复制**：复制这一轮最后的回复；
- **分享**：把这一轮（你说的话，含插队的消息，以及回复）整理成 Markdown 文件，保存到你选的位置；
- **从这里分叉**：复制到这一轮为止的对话，开一个新会话（标题带“· 分支”），在新会话里换个方向继续，原会话不受影响；
- **用量**：这一轮所有模型请求共用的 token 数（输入含缓存，加上输出）；
- 这一轮结束的时间。

## 运行中继续输入：排队与插队

agent 工作时，输入框仍然可以用：

- **排队**（`Enter`）：消息显示为“排队中”，这一轮结束后自动发送。排队的消息可以“移出队列”，也可以改成插队。
- **插队**（`Ctrl+Enter`）：当前这一步（一次模型回复和它发起的工具调用）结束后，消息立即交给模型，不必等整轮结束。
  适合中途补充要求或纠正方向。插队的消息也可以附带附件。

以 `/` 开头的命令不参与排队和插队，照常执行。

## 设置

`Ctrl+,` 打开或关闭设置。右上角的“打开配置文件”直接打开 `~/.dshr/config.toml`。

### 通用设置

| 项目 | 说明 |
|---|---|
| 语言 | 中文（简体）、中文（粵語）、中文（繁體）、English、Deutsch、Ελληνικά、日本語、Español、Français、Português |
| 主题 | 跟随系统、浅色、深色 |
| 配色方案 | 默认配色，以及数据目录 `themes/` 和插件提供的配色方案（见 [配置参考](configuration.md#配色方案)）。开启高对比度时由它决定配色 |
| 关闭窗口时隐藏到托盘 | 默认开启：关闭窗口后运行中的会话在后台继续；点托盘图标恢复窗口，托盘菜单里“退出”才结束程序 |
| 键盘快捷键 | 修改“新会话”“打开或关闭设置”“聚焦输入框”的组合键，或“全部恢复默认” |

### 辅助功能

| 项目 | 选项 |
|---|---|
| 高对比度 | 关闭 / 开启 / 跟随系统（Windows 的“对比度主题”、macOS 的“增强对比度”）。使用按 WCAG AAA 设计的内置配色 |
| 文字大小 | 跟随系统 / 小（90%）/ 默认（100%）/ 大（115%）/ 特大（130%） |
| 高可见性控件轮廓 | 获得焦点的控件加上更粗、更醒目的双层轮廓，鼠标点击时也显示 |
| 减少动态效果 | 跟随系统 / 减少 / 完整。减少时没有过渡和动画 |

### 模型

- **提供商**列表：每个提供商的状态（已就绪 / 未配置密钥）和“编辑”。
- **添加提供商**：“第三方模型提供商”从内置目录选；“自定义模型 API”接入任意 Messages 兼容或 OpenAI 兼容的接口。
- **编辑提供商**：API 密钥（留空时读该提供商的环境变量）、DeepSeek 账号登录、自定义 API 地址、提示词缓存
  （Messages 协议）、模型目录（获取可用模型、添加或删除模型）、删除提供商。
- **插件提供的服务商**：插件导出的模型服务商，点一下加进提供商列表。
- **新会话默认设置**：默认模型、默认思考等级、默认权限模式、默认模式（预设）。

详见 [模型与提供商](providers.md)。

### 扩展

“扩展”页管理 dshr 的所有扩展。内置功能的开关和配置项在重启后生效；JS 插件的开关和文件改动立即生效。

- **MCP 服务器**：添加（名称 + 启动命令）、查看状态和工具数、重连、登录 / 退出登录、移除。参数里有空格、需要环境变量，
  或者是 HTTP 服务器时，请在配置文件里写（见 [MCP 服务器](mcp.md)）。
- **项目说明与 Skills**：编辑全局说明（`~/.dshr/AGENTS.md`）、打开 Skills 文件夹（见 [项目说明与 Skills](instructions-and-skills.md)）。
- **内置功能**：dshr 自己的各个功能模块（文件、搜索、命令、计划、权限模式、沙箱、上下文压缩、预设、子代理……），
  可以单独关闭；有配置项的（如上下文压缩的阈值）直接在下面改。
- **JS 插件**：每个插件一张卡片——版本、说明、提供了什么、声明的权限（“允许”按钮）、密钥、日志、常驻服务的状态、
  更新与回滚、删除。下方可以“新建 JS 插件”“从安装包安装”“从文件夹安装”“打开插件目录”，以及浏览插件索引。

插件的开发与分发见 [插件开发指南](plugins.md) 和 [插件的打包、签名与分发](plugin-publishing.md)。

### 插件的设置页与关于

插件可以在设置里加自己的页面，排在“扩展”之后。最后一页“关于”显示版本、平台、许可证、源码仓库链接，以及第三方组件声明。

## 托盘

关闭窗口时（默认）dshr 隐藏到系统托盘（macOS 是菜单栏），运行中的会话继续工作。托盘菜单：

- **显示 dshr**（或左键单击图标）：恢复窗口；
- **新会话**；
- **退出**：真正结束程序。

## 键盘、读屏与触屏

- 所有操作都能只用键盘完成。窗口里最先的两个 `Tab` 停靠点是“跳到对话内容”和“跳到输入框”，不必先走过长长的会话列表。
- 菜单里用 `↑` `↓` `Home` `End` 移动，`Enter` / 空格选中；`→` 打开二级菜单，`←` 或 `Esc` 返回。
- 支持 Windows 讲述人、NVDA、macOS 旁白等读屏软件：消息、工具状态、计划进度、审批请求都会被读出，“正在回复”“回复完成”
  等状态会播报。
- 最近一次输入来自触摸屏时进入触屏模式：悬停才出现的操作直接显示，长按等于右键。
